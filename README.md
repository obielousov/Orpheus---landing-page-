# Orpheus — Portfolio Website

A fully responsive portfolio website for a Product & Graphic Designer featuring dark and light themes, interactive animations, and modern UI components.

🌐 Live Demo: https://obielousov.github.io/Orpheus---landing-page-/

## Features

- **Dark & Light themes** — user preference is saved with localStorage
- **Animated page transitions** — preloader and scroll reveal effects powered by IntersectionObserver
- **Portfolio slider** — responsive Swiper carousel showcasing recent projects
- **Infinite marquee** — continuously scrolling avatar showcase
- **Responsive navigation** — fixed header with a mobile burger menu
- **Accessibility** — semantic HTML, ARIA attributes, prefers-reduced-motion, and descriptive image alternatives
- **SEO & Social** — Open Graph and Twitter Card metadata

## Tech Stack

- **HTML5** — semantic markup and SEO-friendly metadata
- **SCSS** — modular architecture with reusable partials compiled into CSS
- **Vanilla JavaScript** — framework-free implementation
- **Swiper 12** — responsive portfolio slider
- **Assets** — Google Fonts (Montserrat & Cinzel), SVG icons, and optimized images

## Project Structure

```
.
├── index.html          # semantic markup
├── scss/               # SCSS source files
├── css/                # compiled CSS
├── js/                 # site interactions
└── img/                # images & SVG assets
```

## Run Locally

Clone the repository:

```bash
git clone https://github.com/obielousov/Orpheus---landing-page-.git
```

Open `index.html` in any modern browser.

No installation or build process is required.
